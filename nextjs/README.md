# Next.js

Framework React full-stack: Server Component, Client Component e Route Handler no App Router

- [Next.js](https://nextjs.org)
- [Next.js - Docs](https://nextjs.org/docs)
- [Next.js - MCP](https://nextjs.org/docs/app/guides/mcp)

## MCP

**Instalar somente no projeto local:**

```bash
cd /path/project
claude mcp add --scope local next-devtools -- npx -y next-devtools-mcp@latest
```
